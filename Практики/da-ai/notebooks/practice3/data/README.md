# Данные для практики 3

Отдел данных собрал по вашему коду с практики 2 чистую выгрузку. Очищать на этот раз ничего не нужно — задача в том, чтобы сделать **верные выводы**.

**Исходные файлы не изменяйте.** Вся обработка — только кодом в ноутбуке. При проверке ваш ноутбук будет перезапущен на оригинальных файлах.

## clients.csv — абоненты

В выгрузке все абоненты, которые были **активны на 1 января 2026 года**. Что с ними было дальше — до 31 октября 2026.

| Столбец | Смысл |
|---|---|
| `client_id` | идентификатор абонента |
| `city` | город |
| `tariff` | тариф |
| `tech` | технология подключения: FTTB, xPON, ADSL |
| `connected` | дата подключения |
| `contact_channel` | основной канал обращений в поддержку в 2026 году: чат, телефон или «нет обращений» |
| `status` | активен / расторгнут (на 31.10.2026) |
| `churn_month` | месяц расторжения (пусто, если абонент активен) |

## monthly_churn.csv — помесячный отток по городам

| Столбец | Смысл |
|---|---|
| `month` | месяц, январь–октябрь 2026 |
| `city` | город |
| `active_start` | активных абонентов на начало месяца |
| `churned` | расторгли договор в этом месяце |

**Доля оттока за месяц** = `churned / active_start`.

## Программа удержания

С **1 июля 2026** в **Кургане и Нижнем Тагиле** работает пилотная программа удержания: звонок оператора абонентам с проблемами и скидка на три месяца. В остальных городах программы нет.
