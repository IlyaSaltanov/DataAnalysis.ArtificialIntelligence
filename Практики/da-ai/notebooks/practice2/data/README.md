# Данные для практики 2

Три выгрузки из разных систем оператора связи. Системы ведут разные отделы, и их выгрузки между собой не согласованы.

## subscribers.csv — справочник абонентов (CRM)

Выгрузка на 20.10.2026. Одна строка — **версия записи** об абоненте. Если запись менялась, в выгрузку могли попасть и старые версии.

| Столбец | Смысл |
|---|---|
| `client_id` | идентификатор абонента, формат `RT-123456` |
| `account` | номер лицевого счёта в биллинге |
| `city` | город |
| `tariff`, `speed_mbps` | тариф и скорость по тарифу, Мбит/с |
| `tech` | технология подключения: FTTB, xPON, ADSL |
| `tv_package` | подключено ли ТВ |
| `connected` | дата подключения |
| `traffic_gb` | трафик за сентябрь 2026, ГБ |
| `nps` | оценка из опроса 0–10. Если абонент отказался от опроса — `-1` |
| `status` | активен / расторгнут |
| `updated_at` | когда запись последний раз изменялась |

## tickets.csv — обращения в поддержку (январь–сентябрь 2026)

Выгрузка из системы обращений. Кодировка Windows-1251, разделитель — точка с запятой.

| Столбец | Смысл |
|---|---|
| `ticket_id` | номер обращения |
| `client` | идентификатор абонента в системе обращений |
| `created_at` | время регистрации |
| `category` | категория обращения |
| `channel` | канал: телефон, чат, приложение, офис |
| `comment` | комментарий оператора |

Известные особенности: учётки `TEST-…` — тестовые, их заводят инженеры поддержки. Иногда одно обращение регистрируется системой дважды.

## billing.xlsx — начисления (АСР «Биллинг-М»)

Лист «Начисления»: строка — лицевой счёт, столбцы — месяцы январь–сентябрь 2026. Прочерк — начислений не было.
Тип клиента: ФЛ — физические лица, ЮЛ — юридические.
