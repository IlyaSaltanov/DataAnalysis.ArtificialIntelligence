# Анализ данных и ИИ — комплект для практик

Среда ставится один раз на весь курс. Права администратора не нужны.

## Установка

1. Распакуйте архив в папку без пробелов и облачной синхронизации, например `C:\Users\<имя>\da-ai` или `~/da-ai`.
2. Запустите установку:
   - **Windows:** дважды щёлкните `setup_windows.bat`;
   - **Ubuntu / macOS:** в терминале в этой папке выполните `bash setup_linux.sh`.
3. Дождитесь строки **«СРЕДА ГОТОВА»**. Первый раз это занимает 2–5 минут.

## Работа

- **Windows:** `start_jupyter.bat`; **Ubuntu / macOS:** `bash start_jupyter.sh`.
- Jupyter откроется в браузере. Окно консоли не закрывайте, пока работаете.
- Ноутбуки лежат в папке `notebooks`, данные — в `notebooks/data`.

## Если что-то пошло не так

- Запустите скрипт установки ещё раз: он докачает то, чего не хватает.
- Не помогло — покажите экран преподавателю.
- Запасной вариант: [Google Colab](https://colab.research.google.com). Загрузите туда ноутбук и файл данных через панель «Файлы» и замените в первой ячейке путь `data/subscribers.csv` на `subscribers.csv`.

| Файл | Зачем |

| `notebooks/00_check_env.ipynb` | проверка изнутри Jupyter |
